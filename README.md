# Download Organizer
Automates Organizing the downloads directory by file extension through a task scheduler. 

## How to run
### Windows
Use Windows task scheduler to schedule runners/run_windows.bat

## What I learned

I learned how to schedule a task using either the Windows task scheduler or cron. I think best practice is to schedule a shell script or batch file that executes a Python script rather than directly scheduling the Python script itself.
